# สู้ ๆ นะ น้องแฟร์ ⚖️✨

เว็บเล็ก ๆ เป็นกำลังใจให้ น้องแฟร์ ก่อนสอบกฎหมาย วันที่ 10 ตุลาคม 2026

ทำด้วย HTML + CSS + JavaScript ล้วน ๆ (ไม่ต้อง build, ไม่ต้องติดตั้งอะไร)

## มีอะไรบ้าง

- 🐰 น้องกระต่ายถือตราชั่ง กดแล้วมีข้อความให้กำลังใจสุ่มขึ้นมา
- ⏰ นับถอยหลังสู่วันสอบ (เวลาไทย)
- ✉️ ข้อความถึงแฟร์
- 📜 ประมวลกำลังใจ (เลียนแบบมาตรากฎหมายแบบขำ ๆ)
- ✅ เช็กลิสต์ก่อนวันสอบ (ติ๊กแล้วเครื่องจำให้)
- 🎁 สุ่มรางวัลหลังสอบเสร็จ

## แก้ข้อความ / วันเวลา

- วัน-เวลาสอบ: ด้านบนของ `script.js` (`CONFIG.examDate`, `CONFIG.examTime`)
- ข้อความให้กำลังใจที่สุ่ม: `CHEER_MESSAGES` ใน `script.js`
- รายการเช็กลิสต์: `CHECKLIST`, ของรางวัล: `REWARDS` ใน `script.js`
- ข้อความในจดหมาย / ประมวลกำลังใจ: `index.html`
- สีและหน้าตา: ตัวแปรสีที่ต้นไฟล์ `style.css`

## ลองดูในเครื่อง

```bash
python -m http.server 5173
# แล้วเปิด http://localhost:5173
```

## Deploy

เชื่อม repo นี้กับ [Vercel](https://vercel.com) (Add New → Project → เลือก repo นี้)
Framework Preset เลือก **Other** ไม่ต้องใส่ Build Command ทุกครั้งที่ push ขึ้น `main` Vercel จะ deploy ให้เอง
